# TaskFlow Productivity Tracker

A responsive CRUD task manager built with HTML, CSS, JavaScript, and Vite.

## Features
- Create, view, edit, and delete tasks
- Work, Personal, and Study categories
- Due dates with overdue and due-today labels
- All, Active, and Completed filters
- Category filtering, search, and sorting
- Mark tasks complete or active
- Drag and drop task reordering
- Browser localStorage persistence
- Responsive layout for desktop and mobile

## Run locally
1. Extract this folder.
2. Open it in VS Code.
3. Open a terminal in this folder.
4. Run `npm install`.
5. Run `npm run dev`.
6. Open the local URL printed by Vite, usually `http://localhost:5173`.

## Storage note
Tasks are saved in this browser's localStorage. They stay on this device and browser profile. Clearing browser site data will remove them.
